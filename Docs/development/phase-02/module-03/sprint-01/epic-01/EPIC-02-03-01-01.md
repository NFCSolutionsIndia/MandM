## 1. Epic Objective

Build the three-slide carousel and three-step quiz, with answers that have real consequences.

---

## 2. Business Value

Blueprint §5.1 calls the first-session outcome the highest-leverage change available. This epic is where that lands.

---

## 3. User Stories

> **As a** new user
> **I want** to understand what this product is for in fifteen seconds
> **So that** I can decide whether to invest my family's history in it

> **As a** new user
> **I want** the app to already know who matters to me
> **So that** it feels personal from the first screen instead of empty

---

## 4. Functional Requirements

- Three slides with clear value propositions, swipeable, skippable.
- Quiz: who matters most, which occasions, reminder style.
- Answers persisted and used.
- Resume from the last incomplete step.

---

## 5. Technical Requirements

- Answers stored server-side, not only in local state
- Reminder style maps to a documented notification default set
- Funnel events per step

---

## 6. UI Requirements

- Per §29.2, including the "You can change this anytime" footnote
- Release-1 substitute for the gifts slide
- Chip multi-select

---

## 7. API Requirements

_No new API surface in this epic._

---

## 8. Database Requirements

_No schema changes._

---

## 9. Security Requirements

- Answers are personal data: included in export, removed on deletion
