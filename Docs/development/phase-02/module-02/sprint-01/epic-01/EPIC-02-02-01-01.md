## 1. Epic Objective

Create the vault and membership tables and give every new user a personal vault.

---

## 2. Business Value

Vault membership is the resolution target for every authorization decision in the product. Without it, `authz` has nothing to resolve against.

---

## 3. User Stories

> **As a** new user
> **I want** my own private space created automatically
> **So that** I never have to think about where my memories live

---

## 4. Functional Requirements

- Personal vault created in the same transaction as the user
- Owner membership recorded
- Vault type distinguishes personal from shared and legacy

---

## 5. Technical Requirements

- Creation is transactional with user creation — a user without a vault is an invalid state
- Roles from the `@mm/shared` enum

---

## 6. UI Requirements

_Not applicable._

---

## 7. API Requirements

_No new API surface in this epic._

---

## 8. Database Requirements

- `vaults`, `vault_members` scoped through `lib/authz`
- Unique constraint preventing duplicate membership rows

---

## 9. Security Requirements

- tenant isolation on both tables
- Owner role cannot be removed from a personal vault

---

## 10. Testing Requirements

- Transactional creation
- tenant isolation scoping
- Duplicate membership rejected
