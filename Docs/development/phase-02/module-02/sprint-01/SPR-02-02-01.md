## 1. Sprint Goal

Every read and write goes through `lib/authz`; the permission matrix is executable; tenant isolation independently blocks cross-tenant access.

---

## 2. Scope

### In Scope

- Vault and membership schema
- Vault auto-creation
- `lib/authz` module
- Permission matrix as code plus per-cell tests
- scope enforcement
- Route guards
- Step-up enforcement

### Out of Scope

- Share links and capsule recipients as grant sources (PHASE-05 extends authz)
- Admin realm (PHASE-08)

---

## 3. Technical Approach

- Write the matrix as data, derive both the runtime check and the test suite from it, so they cannot disagree.
- Design `authorize()` to accept a subject, an action, and a resource, and to return a reason on denial — the reason is needed for audit logging and for honest UI copy.
- Add the two grant sources that do not exist yet (share link, delivered capsule recipient) as explicit, currently-empty branches, so PHASE-05 extends rather than redesigns.

---

## 4. Architecture Changes

- Introduces the single most security-critical module in the codebase
