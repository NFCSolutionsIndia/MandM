## 1. Sprint Goal

An operator can log in with hardware MFA, see delivery health at a glance, inspect the job queue, and look up a user without seeing their content.

---

## 2. Scope

### In Scope

- Admin auth realm with TOTP and backup codes
- Delivery health dashboard
- Job queue view
- User lookup with break-glass
- System health
- Audit viewer

### Out of Scope

- Analytics dashboards (Release 2)
- Catalog, orders, promotions (Release 3)

---

## 3. Technical Approach

- Support sees no content by default. Break-glass requires a reason, a second approver, an audit entry, and a notification to the user (§16.3, gap G-8).

---

## 4. Architecture Changes

- Introduces the admin realm on a separate subdomain
