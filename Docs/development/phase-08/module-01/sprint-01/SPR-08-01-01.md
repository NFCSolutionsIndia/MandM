## 1. Sprint Goal

Every content access is recorded, the user can read their own log, and the app can be locked behind a biometric.

---

## 2. Scope

### In Scope

- Audit log entity and writes
- Access log UI
- Default visibility
- App lock and PIN

### Out of Scope

- Admin audit viewer (MOD-08-04)
- Export and deletion (MOD-08-02)

---

## 3. Technical Approach

- Write audit entries from the authz layer where possible, so coverage follows the chokepoint rather than depending on every call site remembering.

---

## 4. Architecture Changes

- Introduces the audit log used by every later sensitive path
