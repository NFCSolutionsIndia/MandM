## 1. Epic Objective

Create the monorepo skeleton with all six workspaces and shared configuration.

---

## 2. Business Value

Every later task depends on knowing where code goes. Ambiguity here produces a codebase nobody can navigate by month three.

---

## 3. User Stories

_Technical epic — no direct user story._

---

## 4. Functional Requirements

- Six workspaces exist: `apps/api`, `apps/workers`, `packages/shared`, `packages/db`, `packages/emails`, `packages/config`.
- Shared ESLint, TypeScript, and Tailwind configuration is consumed, not duplicated.
- A single command runs typecheck, lint, and test across the whole repo.

---

## 5. Technical Requirements

- pnpm workspaces with a lockfile committed.
- Turborepo pipeline with correct `dependsOn` so `packages/*` build before `apps/*`.
- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`, path aliases per workspace.
- Node version pinned via `.nvmrc` and `engines`.
