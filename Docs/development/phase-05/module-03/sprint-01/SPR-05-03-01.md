## 1. Sprint Goal

A recipient opens a delivered capsule on any browser, watches it, replies, and the reply lands in the sender's vault.

---

## 2. Scope

### In Scope

- `/c/[token]` page with all states
- Ceremonial reveal
- Reply capture (text, emoji, voice)
- Save a copy
- Sender notifications
- Soft signup invitation

### Out of Scope

- Collaborative capsules (Release 2)
- Full account linking flows

---

## 3. Technical Approach

- Server-render everything. Progressive enhancement only. The page must work with JavaScript off, which rules out a client-side reveal as the primary path.
- Restraint in the UI: §29.24 requires "no chrome, no branding competing for attention".

---

## 4. Architecture Changes

- Completes the growth loop by turning a reply into a memory in the sender's vault
