## 1. Module Objective

Deliver the memory in a way worthy of the wait, to someone with no account, in a browser we cannot predict.

---

## 2. Business Requirements

- Blueprint §2.2: "The delivery moment *is* the product. A capsule that arrives as a plain email attachment destroys the value created over 13 years."
- It is also the growth loop: the recipient becomes a creator.

---

## 3. Functional Requirements

- Sealed countdown state
- Ceremonial reveal
- Full-screen memory
- Reply with text, emoji, or voice
- Save a copy
- Soft account invitation
