## 1. Epic Objective

Move the drain into the background sync layer, resolve conflicts, and enforce the offline seal block.

---

## 2. Business Value

This is what turns "saved on this device" into "safely uploaded" without the user having to do anything.

---

## 3. User Stories

> **As a** user in a basement
> **I want** to record a memory and forget about it
> **So that** the app finishes the job when signal returns

---

## 4. Functional Requirements

- Background Sync registration and drain
- `periodicSync` where available
- Offline create and patch through the outbox
- Conflict prompt on divergence
- Seal blocked offline with a preserved draft

---

## 5. Technical Requirements

- Drain invoked from the background sync layer using the PHASE-04 outbox unchanged
- Last-write-wins with a user prompt on real divergence
- Idempotency keys prevent duplicates

---

## 6. UI Requirements

- Honest pending states
- Conflict prompt
- Seal-block explanation (§9.4)

## 9. Security Requirements

## 10. Testing Requirements
