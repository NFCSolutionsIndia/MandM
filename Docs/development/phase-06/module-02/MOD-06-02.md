## 1. Module Objective

Deliver the §9.4 offline matrix exactly: full offline capture and creation, cached reads, and one deliberate block.

---

## 2. Business Requirements

- Offline capability is what makes the product usable in the moments memories actually happen — a basement, a plane, a rural wedding.

---

## 3. Functional Requirements

- Precached shell; per-route-class runtime caching; thumbnail LRU.
- Offline reads: recent timeline, memory metadata, capsules, cached thumbnails.
- Offline create and edit through the outbox.
- Background Sync drain.
- Conflict resolution with a prompt.
- Sealing blocked offline with honest copy.
- Update prompt deferring while work is in flight.
