## 1. Epic Objective

Ship a valid manifest and an install flow that respects the user.

---

## 2. Business Value

Install is what unlocks push on iOS and what makes the product feel like an app rather than a website. Getting the timing wrong turns it into a nag that gets dismissed permanently.

---

## 3. User Stories

> **As a** mobile user
> **I want** the app on my home screen
> **So that** my memories are one tap away, like a real app

---

## 4. Functional Requirements

- Manifest with maskable icons, shortcuts, share target
- Install card after first save
- iOS walkthrough
- Dismissal persistence
- Post-install confirmation

---

## 5. Technical Requirements

- `store install` captured and deferred
- Standalone display detection
- iOS has no prompt API — walkthrough only
