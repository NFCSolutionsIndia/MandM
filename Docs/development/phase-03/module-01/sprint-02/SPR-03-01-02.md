## 1. Sprint Goal

A user on any device can populate their member list without typing everything, and can clean up duplicates afterwards.

---

## 2. Scope

### In Scope

- Contact Picker where available
- vCard and CSV upload
- Self-service invite link
- Duplicate detection and merge

### Out of Scope

- Calendar import (no web API exists — see §29.0)
- Social graph import

---

## 3. Technical Approach

- Present four paths as equals (§29.11). On iOS the file and invite paths are primary, so they must feel first-class rather than apologetic.
- The invite link is the highest-quality path and doubles as acquisition — design it as the good option, not the consolation.

---

## 4. Architecture Changes

- Introduces the first public tokenised route beyond auth: `/m/[token]`
