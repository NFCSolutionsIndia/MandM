## 1. Sprint Goal

A user can create a memory dated 1998 with a note, see it, edit it, delete it, restore it, and find it.

---

## 2. Scope

### In Scope

- Memory schema with precision and FTS
- CRUD actions
- Create sheet
- Detail viewer
- Gallery grid
- Trash and purge

### Out of Scope

- Media capture and upload (PHASE-04)
- Semantic search (Release 2)
- Comments (Release 2)

---

## 3. Technical Approach

- Precision-aware date handling is a shared formatter used by every surface, so no screen can render a year-precision date as a specific day.
- Work against seeded media placeholders; PHASE-04 replaces them without touching this module's contract.

---

## 4. Architecture Changes

- Introduces the memory feature module and the FTS pattern
