## 1. Epic Objective

Build the create sheet, detail viewer, and gallery grid.

---

## 2. Business Value

These are the screens where the archive is actually used. The create sheet in particular is where the product asks its one irreplaceable question.

---

## 3. User Stories

> **As a** user
> **I want** to record what a moment meant, not just that it happened
> **So that** the memory keeps its meaning after I have forgotten the details

---

## 4. Functional Requirements

- Create sheet with media tray, precision date picker, and note
- Detail viewer with swipe and zoom
- Gallery grid with multi-select

---
