## 1. Epic Objective

Create the memory schema with `occurred_precision` and full-text search, and the CRUD actions around it.

---

## 2. Business Value

Blueprint §13.1: this one field "is the difference between a real family archive and a broken one".

---

## 3. User Stories

> **As a** family archivist
> **I want** to record that a photo is from 1974 without inventing a day
> **So that** my archive tells the truth about what I know

---

## 4. Functional Requirements

- Create, update, soft-delete, restore
- Precision-aware storage and formatting
- Favourites
- Occasion tagging
- FTS

---

## 5. Technical Requirements

- Generated `search_text` column with a tsvector GIN index index
- Precision-aware sort and display
- Idempotent create by `client_id` for offline use in PHASE-06
