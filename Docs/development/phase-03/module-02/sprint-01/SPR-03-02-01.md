## 1. Sprint Goal

An event with a yearly recurrence and reminder offsets produces the right occurrences and fires each reminder exactly once.

---

## 2. Scope

### In Scope

- Event schema
- Recurrence computation
- Reminder offset scheduling
- Auto-derived member occasions

### Out of Scope

- Calendar UI (next sprint)
- Festival packs (Release 2 admin)
- Broadcasts (Release 2)

---

## 3. Technical Approach

- Compute occurrences rather than materialising them — a yearly event must not create fifty rows (§34.2).
- Guard reminders with `last_fired_for_year` so a restart or a clock adjustment cannot double-send.
- Do all date arithmetic on absolute instants with an explicit timezone (ADR-024).
