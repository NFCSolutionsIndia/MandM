## 1. Epic Objective

Build the three calendar views and event CRUD per blueprint §29.12.

---

## 2. Business Value

This is where "what is coming up" becomes visible, and it is the screen that converts an archive into a product that prompts action.

---

## 3. User Stories

> **As a** user
> **I want** to see the year ahead at a glance
> **So that** I can plan what to make and for whom

---

## 4. Functional Requirements

- Month grid, year heat view, agenda list
- Today control
- Event chips by type
- Add/edit event
- Event detail sheet with countdown and planned-items checklist

---

## 5. Technical Requirements

- One query per view range using computed occurrences
- Region-aware festival display, toggleable

---

## 6. UI Requirements

- Per §29.12 including the empty-month copy
- Type-coloured chips with recurrence indicator
- Detail sheet with countdown ring
