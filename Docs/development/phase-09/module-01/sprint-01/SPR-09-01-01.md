## 1. Sprint Goal

Every authorization property is proven by test, an external tester finds no exploitable cross-tenant access, and CSP and rate limits are enforced.

---

## 2. Scope

### In Scope

- Matrix and tenant-isolation assurance
- IDOR suite
- Pen test and remediation
- CSP with nonces
- Security headers
- Edge rate limits
- Dependency scanning

### Out of Scope

- Quality and accessibility (MOD-09-02)
- Resilience (MOD-09-03)

## 3. Technical Approach

- Run the pen test early in the phase so remediation fits inside it. Treat the negative-path suite as a permanent regression asset, not a one-off exercise.
