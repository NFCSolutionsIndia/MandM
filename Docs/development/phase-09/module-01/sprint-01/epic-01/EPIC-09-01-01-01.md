## 1. Epic Objective

Prove that no user can reach another user's content through any path, at both layers, adversarially.

---

## 2. Business Value

This epic exists to close gap R-2. Its output is not a feature but a set of permanent regression tests that make the property durable as the codebase grows.

---

## 3. User Stories

> **As a** user
> **I want** certainty that no other user can reach my family's photographs
> **So that** I can trust this product with the only copy of them

---

## 4. Functional Requirements

- Per-cell matrix coverage including the PHASE-05 grant sources
- tenant isolation verified with the application layer bypassed
- Cross-tenant attempts through every endpoint
- Token-handling verification
- External pen test

---

## 5. Technical Requirements

- Generated matrix tests
- Direct-SQL tenant-isolation tests
- An endpoint-enumerating negative suite
