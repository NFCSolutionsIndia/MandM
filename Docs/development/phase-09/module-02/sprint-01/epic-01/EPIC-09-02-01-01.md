## 1. Epic Objective

Cover the critical path, verify accessibility with real assistive technology, and confirm behaviour on real devices.

---

## 2. Business Value

The critical path is the promise. Accessibility is the audience. The device lab is where the §29.0 platform gaps stop being theoretical.

---

## 3. User Stories

> **As a** user
> **I want** the whole flow to work reliably
> **So that** my memories arrive as promised

> **As a** user with a screen reader
> **I want** to use the product independently
> **So that** my memories are mine to manage

> **As a** user with a five-year-old Android
> **I want** the app to be usable
> **So that** the product is not only for new phones

---

## 4. Functional Requirements

- E2E: signup → capture → seal → deliver → open → reply
- Offline and install E2E
- axe on every screen
- Screen-reader pass
- Device matrix
- Benchmarks

---

## 5. Technical Requirements

- Playwright with virtual authenticator for passkeys
- axe integrated into Playwright
- Throttled CPU and network profiles
- Real devices for the apps gaps
