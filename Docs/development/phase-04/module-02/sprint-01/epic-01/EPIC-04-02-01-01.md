## 1. Epic Objective

Create the media and session entities and the endpoints that make resumable direct-to-storage upload possible.

---

## 2. Business Value

Blueprint §12.1: "without server-side upload state, a mobile upload interrupted at 80% must restart. Unacceptable for a 4K video on cellular."

---

## 3. User Stories

> **As a** user on a train
> **I want** my upload to pick up where it left off
> **So that** a tunnel does not cost me the whole video again

---

## 4. Functional Requirements

- Create session with part plan
- Presign parts
- Report progress
- Complete with checksum verification
- Query session state for resume

---

## 5. Technical Requirements

- R2 multipart API
- Part manifest with ETags
- SHA-256 verification
- Transactional storage accounting

---

_Not applicable._

## 8. Database Requirements

- `media_assets`, `upload_sessions` scoped through `lib/authz`; foreign key from `memories.cover_media_id`

---

## 9. Security Requirements

- Quota and caps before presigning
- Magic-byte validation on complete
- SVG rejected
- Private bucket asserted by test

---

## 10. Testing Requirements
