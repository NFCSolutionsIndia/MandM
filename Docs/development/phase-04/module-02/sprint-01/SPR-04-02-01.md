## 1. Sprint Goal

A client can open an upload session, receive presigned part URLs, upload parts directly to R2, resume after interruption, and complete with checksum verification.

---

## 2. Scope

### In Scope

- MediaAsset and UploadSession schema
- Presign endpoint
- Complete/verify endpoint
- Quota enforcement
- Storage accounting

### Out of Scope

- Client chunker (next sprint)
- Derivatives (MOD-04-03)

---

## 3. Technical Approach

- Server owns the part manifest so a client that lost its state can ask what is already uploaded.
- Enforce quota and size caps before presigning, so a rejected upload costs nothing.

---

## 4. Architecture Changes

- Introduces R2 and the per-vault key layout
