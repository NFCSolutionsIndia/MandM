## 1. Sprint Goal

A user can record on airplane mode, close the app, come back online, and find the memory uploaded without touching anything.

---

## 2. Scope

### In Scope

- Chunker with parallel parts and resume
- the on-device store outbox with backoff
- Queue UI with controls
- Connection-aware behaviour
- Storage persistence request

### Out of Scope

- OS background transfer (PHASE-06 generalises this)
- Offline reads (PHASE-06)

---

## 3. Technical Approach

- Build the outbox now with the state machine PHASE-06 will drive from the background sync layer, so that phase is a relocation rather than a rewrite.
- Make the queue honest and controllable — §29.28 requires a visible tray with per-item retry.

---

## 4. Architecture Changes

- Introduces the outbox state machine reused by PHASE-06 for all offline writes
